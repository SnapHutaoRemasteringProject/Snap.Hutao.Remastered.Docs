# MSIX の更新とインストール形式の切り替え

正式版の MSIX 2.0.1 と 2.0.2 は同じパッケージ ID を使用します。署名済みの 2.0.2 MSIX を上書きインストールすると、既存のアプリデータをそのまま利用できます。

MSIX 版と Setup 版を切り替える場合は、設定で実際のデータフォルダーを確認し、タスクトレイを含めて胡桃を完全に終了してからバックアップしてください。切り替え先の版をインストールし、その版のデータフォルダーを確認します。フォルダーが異なる場合は、胡桃を終了して移行先の既存ファイルをバックアップし、`Userdata.db` など必要なデータをコピーしてください。再起動してアカウントや祈願履歴を確認し、移行が完了するまでバックアップと切り替え前のアプリを残してください。一部の設定は再設定が必要な場合があります。
