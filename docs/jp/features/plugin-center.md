# 插件中心

插件中心是 Snap Hutao 提供的可扩展插件系统，允许用户安装和管理第三方插件，从而灵活扩展胡桃工具箱的功能。
所有已安装的插件将在程序启动时自动加载，用户可在插件中心页面统一管理。

## 安装插件

![插件中心](/images/202608/plugin-center.webp)

::: tip 插件格式
胡桃工具箱的插件文件以 `.hutao` 为扩展名，实际为包含插件清单、程序集和可选资源文件的 ZIP 压缩包。
:::

1. 打开胡桃工具箱，进入左侧导航栏的**插件中心**页面
2. 点击工具栏上的**安装插件**按钮
3. 在文件选择器中选择一个 `.hutao` 插件文件
4. 程序将自动解压并验证插件包中的 `manifest.json`，确认无误后完成安装
5. 安装成功后，插件将出现在插件列表中

## 管理插件

插件中心页面以卡片形式展示所有已安装的插件，每张卡片包含以下信息：

- **插件图标**：由插件包内的 `icon.png` 提供，若无图标则显示默认图标
- **插件名称与描述**：来自插件清单中的 `name` 和 `description` 字段
- **版本号**：展示插件的当前版本
- **作者信息**：显示插件的作者列表
- **状态标识**：以彩色标签展示插件当前处于**已启用**或**已禁用**状态

### 启用与禁用插件

- 点击插件卡片上的**启用**按钮可激活插件，程序将调用插件的 `OnEnable()` 生命周期方法
- 点击**禁用**按钮可停用插件，程序将调用插件的 `OnDisable()` 方法并释放相关资源
- 启用/禁用的状态切换同时会重命名插件文件扩展名（`.hutao` ↔ `.hutaodisabled`）

### 卸载插件

1. 点击插件卡片上的**卸载**按钮
2. 在确认对话框中确认操作
3. 程序将先禁用插件，再删除插件文件，完成卸载

### 其他操作

- **刷新**：点击工具栏的刷新按钮，重新扫描并加载插件目录
- **打开插件目录**：点击工具栏的文件夹按钮，在资源管理器中打开插件存放目录

## 插件设置

如果插件提供了可配置的设置项，点击插件卡片上的**设置**按钮即可进入该插件的设置页面。

设置页面会根据设置项的值类型提供不同的输入控件：

- **字符串类型**：使用文本输入框（TextBox）
- **整数类型**：使用数字输入框（NumberBox）
- **布尔类型**：使用开关控件（ToggleSwitch）

每个设置项均提供**保存**和**重置为默认值**按钮，方便用户调整和恢复设置。

## 游戏内 DLL 注入

::: important 高级功能
DLL 注入为插件系统的高级功能，仅在通过胡桃工具箱启动游戏时生效。
:::

当用户通过胡桃工具箱启动游戏时，程序会遍历所有已启用插件，检查其插件包内是否包含 `inject/` 目录。若存在该目录，其中的所有 `.dll` 文件将被注入到游戏进程中。

此功能允许插件在游戏运行时与游戏进行交互，实现更丰富的功能扩展。

## 插件开发

::: tip 开发者信息
如需开发自己的胡桃工具箱插件，请参考 `Snap.Hutao.Plugin.SDK` NuGet 包。该 SDK 提供了插件基类 `HutaoPlugin`、设置管理 `PluginSetting<T>`、自定义页面 `PluginScopedPage` 等核心 API。
:::

插件开发的基本步骤：

1. 创建 .NET 类库项目，安装 `Snap.Hutao.Plugin.SDK` 包
2. 创建继承 `HutaoPlugin` 的主类，并使用 `[PluginMain]` 特性标记
3. 实现 `OnInstall()`、`OnLoad()`、`OnEnable()`、`OnDisable()`、`OnUninstall()` 生命周期方法
4. 在 `manifest.json` 中填写插件元数据（名称、ID、版本、作者、描述）
5. 将编译后的 DLL、`manifest.json` 和可选的 `icon.png` 打包为 `.hutao`（ZIP 格式）
