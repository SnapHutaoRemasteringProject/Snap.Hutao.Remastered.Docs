# 更新日志
## 1.19.1 Release<Badge text="最新版" type="tip" />

- **【🎉新增】** 我的角色页面支持批量导出角色练度情况为文本文档 [#82]
- **【🎉新增】** 主界面显示活动剩余时间倒计时 [#76]

- **【🎉新增】** 程序自启动功能（Win11完整支持，Win10支持有限）

- **【✨优化】** 内部程序更新适配 [#96]

- **【🔨修复】** 修复了下载更新游戏时如果取消可能会导致的窗口无法关闭问题
- **【🔨修复】** 修复了暂停按钮的文字重叠
