# 🎉 バージョン 1.20.0 への更新に成功しました

**简体中文** | [English](/en/statements/latest.html)

- **【🎉新機能】** バックパックアイテムページを追加（アイテムフィルタ、動的ソート、詳細表示に対応）
- **【🎉新機能】** 聖遺物スコア機能を追加 #158
- **【🎉新機能】** 武器と聖遺物にロックとマークアイコンを追加
- **【🎉新機能】** 自動化タスクで BetterGI のパスを手動入力可能に #232
- **【🎉新機能】** 育成計画でバックパックアイテムのアーカイブからアイテムを同期可能に
- **【🎉新機能】** Mirror醬 (MirrorChyan) ダウンロードチャンネルと自動更新対応を追加

- **【✨最適化】** 育成計算を最適化 #220
- **【✨最適化】** バックパックアイテムのパフォーマンスを最適化
- **【✨最適化】** 祈願ページのコピーオーバーヘッドを削減
- **【✨最適化】** 育成パラメータ変更後にポップアップメニューを自動で閉じるように
- **【✨最適化】** 低バージョンの Windows の実行をブロックせず、初回に警告を表示するように変更

- **【🔨修正】** 7.0 前半の背景動画が再生されない・異常表示される問題を修正
- **【🔨修正】** ゲームインストール時のクラッシュを修正
- **【🔨修正】** FileUnlocker によるメタデータ更新の停止を修正
- **【🔨修正】** Toast 通知の補助プロセスが未登録の場合のクラッシュを修正 #216
- **【🔨修正】** ゲーム起動によるウィンドウクローズ後の復元時に重複ウィンドウが表示される問題を修正 #238
- **【🔨修正】** キャラクターページのスキルレベル選択 ComboBox の高さエラーを修正 #242
- **【🔨修正】** Embedded Yae の実績インポートエラーを修正 #246
- **【🔨修正】** バックパックアイテムの材料で空アイテムが表示される問題を修正
- **【🔨修正】** 濃縮樹脂が貴重品ではなく材料に分類される問題を修正
