# 🎉 バージョン 1.19.8 への更新に成功しました

**简体中文** | [English](/en/statements/latest.html)

- **【🎉新機能】** ゲーム起動時にメインウィンドウを自動的に閉じ、ゲーム終了時に自動復元 #195
- **【🎉新機能】** 胡桃通行証登録に同意チェックボックスを追加
- **【🎉新機能】** 実績グリッドビューに獲得原石/合計原石数を表示 #219

- **【✨最適化】** 胡桃通行証登録時にユーザーにデータ問題について警告
- **【✨最適化】** フレームレート上限を調整
- **【✨最適化】** バックアップドメインへの自動切替時に永続設定を変更しないように
- **【✨最適化】** ゲーム起動エラーメッセージを強化

- **【🔨修正】** 特定の状況でダウンロードページがフリーズする問題を修正
- **【🔨修正】** UIDチェックボックス欠落によるUIGF v3.0エクスポート失敗を修正 #217
- **【🔨修正】** 胡桃通行証ログイン後BetterGIでゲーム起動時に再ログインが必要な問題を修正 #151
- **【🔨修正】** タブ切り替え時にお知らせページが二重に更新される問題を修正 #118
- **【🔨修正】** トレイに最小化後ウィンドウが復元できない問題を修正
- **【🔨修正】** 祈願記録の操作ボタンが縦スクロールバーで隠れる問題を修正
