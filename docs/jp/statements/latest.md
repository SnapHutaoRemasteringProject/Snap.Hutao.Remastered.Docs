# 🎉 バージョン 2.0.2 への更新に成功しました

**简体中文** [zh](/zh/statements/latest) · **繁體中文** [tw](/tw/statements/latest) · **English** [en](/en/statements/latest) · **日本語** [jp](/jp/statements/latest) · **Bahasa Indonesia** [id](/id/statements/latest) · **Русский** [ru](/ru/statements/latest)

このリリースでは、Windows 10 の便利メモ用ライブタイルを追加し、**ゲームの実行状態の検出とプロセス管理**を改善しました。Island のキャサリンへのリダイレクトをすべてのユーザーに公開し、一部のユーザーが米游社（MiYouShe）にログインできない問題も修正しました。

### 🎉 新機能

- **【🎉新機能】** ゲーム起動画面で、胡桃を使わずに起動した『原神』を自動検出し、実行状態の表示やゲームプロセスの終了ができるようになりました。
- **【🎉新機能】** Island のキャサリンへのリダイレクト設定をすべてのユーザーが利用できるようになりました。
- **【🎉新機能】** Windows 10 の MSIX 版に、天然樹脂やデイリー依頼の進捗を表示する便利メモのスタートメニュー用ライブタイルを追加しました。キャラクターを検索し、名刺を背景に設定できます。
- **【🎉新機能】** Island に「旧パイモンメニュー」設定を追加し、パイモンメニュー内の「星々のショップ」と人気のワンダーの配置を元に戻せるようにしました。
- **【🎉新機能】** インストーラーに画像を同梱できるようになりました。ストレージ設定から同梱画像と内容が同じキャッシュを削除できます。

### ✨ 改善

- **【✨改善】** 不要なプロセスの検索を減らし、OS のプロセス終了通知を使って実行状態をすばやく更新するようにしました。
- **【✨改善】** 管理者権限で胡桃を起動しなくても、同じ権限レベルで実行中のゲームプロセスの終了を試みることができます。
- **【✨改善】** ゲームプロセス終了後の状態確認を改善しました。該当するプロセスが複数ある場合に対応し、失敗時はより明確なエラーメッセージを表示します。
- **【✨改善】** MSIX 版と画像同梱の Setup 版は、初回設定時の一括ダウンロードを省略し、不足する画像を必要に応じて取得します。通常の Setup 版ではカテゴリ別の事前ダウンロードも利用できます。
- **【✨改善】** キャサリンへのリダイレクトに、アニメーション付きの操作ガイドを追加しました。
- **【✨改善】** 保存したテーマを各ウィンドウとダイアログに適用し、設定画面のアニメーションと翻訳を改善しました。
- **【✨改善】** 『原神』7.1 の新しい素材カテゴリに対応しました。

### 🔨 修正

- **【🔨修正】** 一部のユーザーが米游社にログインできない問題を修正しました。
- **【🔨修正】** 胡桃を使わずにゲームを起動または終了した際、実行状態の更新が遅れる問題を修正しました。
- **【🔨修正】** ゲームプロセス終了後も Island が接続済みと表示されることがある問題を修正しました。
- **【🔨修正】** 一部の読み取り専用プロパティの変更通知で、ゲーム起動画面の `x:Bind` バインディングが更新されない問題を修正しました。
- **【🔨修正】** アクセスできないプロセスや複数の該当プロセスがある場合、ゲームの終了操作でエラーが発生する問題を修正しました。
- **【🔨修正】** リモート機能設定の取得に失敗した結果が長時間キャッシュされ、再試行が遅れる問題を修正しました。
- **【🔨修正】** 祈願履歴の取得画面で一覧をスクロールできない問題を修正しました。
- **【🔨修正】** 便利メモのカードで、更新時刻が UID と重なる問題を修正しました。
- **【🔨修正】** Island のアカウント確認がネットワークエラーやタイムアウトで失敗するとゲームが終了する問題を修正しました。警告を表示してゲームを継続します。
- **【🔨修正】** `config.ini` に `game_version` が重複している場合のバージョン検出と修復を修正し、INI のコメントとセクション見出しの処理を改善しました。
- **【🔨修正】** 通常祈願と千の星のワンダーランドの祈願の照会を分離し、手入力およびウェブキャッシュの祈願 URL の検証を改善しました。祈願メタデータが見つからない場合のエラー表示も翻訳しました。
- **【🔨修正】** バッグ内アイテムの同期に失敗すると、保存済みデータが消えることがある問題を修正しました。
- **【🔨修正】** 初回設定時に停止した画像のダウンロードが速やかに終了しない問題を修正しました。
- **【🔨修正】** プラグイン設定をクリアしても古い値が使われる問題と、一部のドロップダウン項目が空欄になる問題を修正しました。
- **【🔨修正】** ウィンドウを閉じた後の終了待ちと、アカウントの初期化時に発生するエラーを修正しました。
- **【🔨修正】** ナド・クライとスネージナヤのキャラクター所属アイコンを復元しました。

### 利用時の注意

ゲームがより高い権限で実行されている場合は、ゲームを終了するために胡桃を管理者として起動する必要がある場合があります。
