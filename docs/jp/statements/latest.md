# 🎉 バージョン 1.20.2 への更新に成功しました

**简体中文** | [English](/en/statements/latest.html)

- **【🎉新機能】** 旅行者ノートカードに「今月の原石入手元の内訳」ページを追加し、ドーナツチャートで構成を表示
- **【🎉新機能】** 育成計画が米遊社経由でのキャラクターレベルと天賦の同期に対応
- **【🎉新機能】** カードガチャ更新後 7 日間は素材秘境の制限を解除、カレンダーカードにも開放のヒントを表示
- **【🎉新機能】** 至冬（スネージナヤ）の新素材の入手スケジュールを追加
- **【🎉新機能】** 樹脂アイテムの項目をオフにする際に二段階確認を追加
- **【🎉新機能】** 「バックグラウンドで実行中」通知をオフにできるように #260

- **【✨最適化】** バックパックの聖遺物を SortOrder 順に並べ替えるように変更
- **【✨最適化】** バックパックページのアイテムレアリティフィルタを削除
- **【✨最適化】** バックパックの聖遺物アイコンのグレー背景を削除
- **【✨最適化】** カレンダー育成カードの素材リストが縦スクロールに対応
- **【✨最適化】** 「目標フレームレート」が機能しない場合のトラブルシューティングのヒントを追加 #262
- **【✨最適化】** Mirror醬 CDK 交換ダイアログに説明を追加
- **【✨最適化】** カウントダウン確認ダイアログの操作感と表示スタイルを最適化

- **【🔨修正】** ネットワーク状態の誤判定により「現在ネットワークが利用できません」のままになる問題を修正 #268
- **【🔨修正】** 予備ドメイン使用時の自動更新の失敗を修正 #265
- **【🔨修正】** 素材秘境の開放曜日と素材スケジュールのデータを修正
