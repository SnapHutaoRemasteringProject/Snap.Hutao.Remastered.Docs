# 🎉 バージョン 2.0.1 への更新に成功しました

[简体中文](/zh/statements/latest.html) | [繁體中文](/tw/statements/latest.html) | [English](/en/statements/latest.html) | **日本語**

- **【🎉新機能】** 「アカウント履歴分析」専用ウィンドウを追加。設定のネットワーク項目、および祈願履歴・深境螺旋・幻想シアター・幽境の激戦の各ページから起動可能 #335
- **【🎉新機能】** ローカルの履歴から、通常祈願と千星奇域の祈願を分けた月別回数・祈願種別の分布、深境螺旋の星数、幻想シアターのメダル数、幽境の激戦の難易度別ソロクリア時間をグラフ表示 #335
- **【🎉新機能】** 既存の祈願統計による星5キャラクター・武器の記録、平均入手回数、現在の天井進捗、ピックアップ・確定状況を AI 分析に活用。記録の欠落をゼロとは見なしません #335
- **【🎉新機能】** アカウント履歴分析に任意の AI アシスタントを追加。手動分析、ストリーミング Markdown 回答、履歴に関する複数ターンの追加質問に対応 #335
- **【🎉新機能】** OpenAI Chat Completions、OpenAI Responses、Anthropic API に対応。接続先、API キー、モデル、推論パラメーターを設定可能 #335
- **【🎉新機能】** AI 会話の保存と管理、モデル切り替え、回答の再生成、会話のコピー、トークン使用量表示、許可が必要なツールの承認・拒否に対応 #335
- **【🎉新機能】** リキッドグラスの ToggleSwitch に全体スケール設定を追加。既定値は 0.7、文字サイズは変更しません
- **【🎉新機能】** リキッドグラスの光学パラメーターとポインター照明設定を拡張。変更はすぐに反映されます
- **【🎉新機能】** 更新通知に「このバージョンをスキップ」を追加。自動確認時の再通知を抑制し、手動での更新確認は引き続き可能
- **【🎉新機能】** Island に「キャサリンへのリダイレクト」を追加。冒険の証のデイリー依頼ショートカットから報酬受け取り画面を直接開けます。対応する Island コンポーネントが必要です
- **【🎉新機能】** ゲーム起動ページに「インストール情報を更新」を追加。config.ini と ScriptVersion を個別に表示し、不一致・欠落・読み取り失敗を通知
- **【🎉新機能】** AI 分析に使うアカウント履歴の統計サマリーをコピー可能。設定したモデルの API キーは Windows の資格情報コンテナーに保存

- **【✨最適化】** ReadyToRun（R2R）事前コンパイルを既定で有効化。実行時の JIT 負荷を減らし、起動速度や一部操作の応答性の向上を図るとともに、MSIX とインストーラーの公開処理を改善 #334
- **【✨最適化】** OpenAI 互換サービスのモデル取得・名前表示・選択を改善。再取得時もカスタム名・設定・選択を保持し、重複・無効な ID を除外
- **【✨最適化】** AI の思考内容を初期状態で折りたたみ、展開してスクロール表示可能に。モデル設定と履歴分析ウィンドウ、削除操作の表示も改善
- **【✨最適化】** リキッドグラスの設定検証・保存・復元を強化。拒否された変更を元に戻し、他の未保存設定を不用意に上書きしません
- **【✨最適化】** Fluent とリキッドグラスの文字色、カードの角丸と影、カレンダーの素材アイコン、ログインカードの装飾を改善 #325
- **【✨最適化】** Flyout・ComboBox・NumberBox などの Acrylic 表示とポップアップ動作を改善
- **【✨最適化】** 画像キャッシュの取得を UI コールバックから分離し、非同期ロックやページ終了処理を改善して描画停止や競合を抑制
- **【✨最適化】** 実績のインポート後の完了数表示、初期設定ガイドの復帰処理、Crowdin 翻訳を改善

- **【🔨修正】** config.ini と ScriptVersion が食い違う際にインストール済みバージョンを誤判定する問題を修正。不一致時はバージョン依存の更新・事前ダウンロードを停止し、完全検証と修復は引き続き可能
- **【🔨修正】** ゲーム更新時に古いインストール情報を使用する問題を修正。操作前に再確認し、リソースの検証完了後にバージョンを更新。チャンネル設定・バックアップを保持し、失敗時はロールバック
- **【🔨修正】** Island 使用時、ゲームバージョンと対応 DLL の互換性確認が不十分だった問題を修正。通常起動は制限しません
- **【🔨修正】** 非 MSIX 版の自動起動タスクが誤った実行ファイルを参照し、登録失敗時に設定表示がずれる問題を修正
- **【🔨修正】** AI モデルの名前が空白になる、選択が消える、追加時に例外が発生する、大量取得時に不安定になる問題を修正
- **【🔨修正】** 外部 AI 設定ファイルの再読み込みにより、新しいローカル設定や認証情報の変更が上書きされる問題を修正
- **【🔨修正】** AI ツール呼び出しの承認・拒否ボタンと、代替表示されるツール名・引数のバインディングを修正
- **【🔨修正】** 公開した MSIX・インストーラーに必要なネイティブライブラリや依存ファイルが含まれない問題を修正。パッケージ化前の検証を追加
- **【🔨修正】** リキッドグラス無効化後も背景が残る、テンプレートのバインディングが壊れる、文字色が不正になる問題を修正 #317
- **【🔨修正】** 一部のリキッドグラスのドロップダウン・ポップアップ・コントロールで操作結果が正しく表示されない問題を修正 #308
- **【🔨修正】** デイリーノートの通知スイッチで設定変更が直ちに表示に反映されない問題を修正
- **【🔨修正】** アカウントのキャラクター選択、既存アカウントの再追加、自動サインインの一覧取得時のスレッド競合を修正 #318 #326
- **【🔨修正】** ホットキー有効状態がプロパティ通知の再入によって古い値に戻る問題を修正 #327
- **【🔨修正】** 育成計画のカード削除後に一覧・共通ポップアップが更新されず、削除済み項目が保存される問題と、ポップアップがカード操作を妨げる問題を修正 #329
- **【🔨修正】** HTTP リトライ時にリクエスト内容が再送されない問題と、Windows セッションのロック・解除による背景動画の再生状態異常を修正 #320 #323
- **【🔨修正】** 胡桃パスポートのパスワード再設定画面の例外と、会話スキップ制限解除の確認ダイアログのカウントダウンを修正
- **【🔨修正】** カレンダー素材の材質切り替えバインディング、一部キャラクターアイコン・スキル説明文の欠落、祈願統計の表示切り替え操作を修正 #313

> 注意：AI 分析はモデルサービスを設定したうえで手動で実行する機能です。サービスには履歴の集計と祈願統計が送られ、アカウントデータベース全体は送信しません。UID などの直接識別情報を除いても、特徴的な履歴から関連付けられる可能性があります。外部サービスのプライバシーポリシーをご確認ください。
