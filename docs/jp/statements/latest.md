# 🎉 バージョン 1.19.1 への更新に成功しました

**简体中文** | [English](/en/statements/latest.html)

- **【🎉新機能】** マイキャラクターページでキャラクター育成状況の一括エクスポートをテキスト文書としてサポート [#82]
- **【🎉新機能】** メインインターフェースにイベント残り時間のカウントダウンを表示 [#76]
- **【🎉新機能】** バックグラウンドタスクの状態表示で、無応答と誤判定されるのを回避
- **【🎉新機能】** プログラム自動起動機能（Windows 11完全対応、Windows 10は限定的対応）
- **【🎉新機能】** 新しい更新ダウンロード進捗グラフUI表示（最終効果ではなく、まだ最適化中）
- **【🎉新機能】** ゲーム更新/修復プロセスで一時停止と再開をサポート
- **【🎉新機能】** カスタム起動：ゲーム起動時にワンクリックでより多くのアプリケーションを起動可能

- **【✨最適化】** 内部プログラムの更新適応 [#96]
- **【✨最適化】** OOBE段階でメンテナー通知を追加：胡桃リマスター版は原作者によるメンテナンスではありません [#90]
- **【✨最適化】** 起動時のネットワーク復旧後、機能が自動的に回復
- **【✨最適化】** 胡桃アカウントログイン失敗検証メカニズムを最適化

- **【🔨修正】** ゲーム終了後にプロセスが終了しない問題を修正 [#98]
- **【🔨修正】** ゲームプロセスの異常終了を修正 [#92]
- **【🔨修正】** 祈願記録の更新時に発生する例外を修正 [#78]
- **【🔨修正】** キャラクター育成追加時のエラーを修正 [#87]
- **【🔨修正】** Deployment.exeが一部のウイルス対策ソフトでMalgent!MSRと誤検知される問題を処理 [#91]
- **【🔨修正】** ゲーム更新ダウンロードキャンセル時にウィンドウが閉じない可能性がある問題を修正
- **【🔨修正】** 一時停止ボタンのテキスト重なりを修正
