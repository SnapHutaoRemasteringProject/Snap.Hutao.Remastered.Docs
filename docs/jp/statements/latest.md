# 🎉 バージョン 1.20.4 への更新に成功しました

**简体中文** | [English](/en/statements/latest.html)

- **【🎉新機能】** 設定ページに「コントロールのマテリアル」を追加し、ネイティブ Fluent とリキッドグラスを切り替えてプレビューできるように #279
- **【🎉新機能】** リキッドグラスをコントロールの種類ごとに有効化でき、ぼかし・屈折・ハイライトなどの光学パラメータを調整してリアルタイムにプレビュー可能 #279
- **【🎉新機能】** オフラインモードを追加：サーバーに接続できない場合はローカルのリポジトリリストを使用し、再接続の入口を用意
- **【🎉新機能】** 「マイキャラクター」ページでキャラクターごとに聖遺物スコアアルゴリズムを選択可能。米遊社のおすすめステータス、内蔵のスコアプリセット、カスタムスコア設定から選択できる #269
- **【🎉新機能】** バックパックのアイテムに装備状態フィルター（装備中 / 未装備）と装備キャラクターのバッジを追加し、詳細フライアウトに装備情報を表示
- **【🎉新機能】** バックパックの聖遺物に祝聖の霜のマークとフィルターを追加し、祝聖の霜で定義されたサブステータスを確認可能
- **【🎉新機能】** 聖遺物のサブステータスを有効 / 無効 / 会心 / 未発動で色分けし、未発動の4番目のサブステータスを表示
- **【🎉新機能】** ホームのリアルタイムノートカードに更新ボタンを追加 #281
- **【🎉新機能】** バージョン 7.1 のキャラクター ID と新しい素材タイプを追加

- **【✨最適化】** プラグインシステムをリファクタリング：プラグインを無効化するとアセンブリを解放し、プラグイン設定の保存 / リセット時に結果を通知
- **【✨最適化】** Yae を 5.5.0 プロトコルにアップグレードし、カスタムパケットの購読に対応
- **【✨最適化】** バックパックのアイテム一覧のパフォーマンスを最適化し、切り替えや更新時のカクつきを低減
- **【✨最適化】** 聖遺物スコア設定ダイアログ：キャンセル時に保存しない、削除を単一トランザクションに統合、プリセット切り替え時に元に戻らない、保存時に既存の変更を破棄しない
- **【✨最適化】** 背景動画のスレッド制御を最適化し、バックグラウンドのリソース使用量を低減
- **【✨最適化】** 背景画像をデコードできない場合にヒントを表示し、黙ってスキップしないように
- **【✨最適化】** 既定の言語選択と地域言語のマッチングを改善：システム UI 言語で対応言語を照合し、簡体字 / 繁体字中国語の区別を維持 #117
- **【✨最適化】** .NET 11 にアップグレードし、依存関係を更新

- **【🔨修正】** 「管理者として自動的に再起動」が有効な場合にプロトコル引数が失われ、`hutao://launch/` でゲームを直接起動できない問題を修正 #305
- **【🔨修正】** 育成計画でキャラクターレベルと天賦を同期する際、命ノ星座のボーナスが考慮されない問題を修正 #307
- **【🔨修正】** 育成計画がバックパックのセーブデータ経由で同期する際、一部の地域特産品の数が同期されない問題を修正 #280
- **【🔨修正】** 自動チェックインが現在のアカウントのみをチェックインする問題を修正 #302
- **【🔨修正】** 背景動画がシステムの SMTC を占有する問題を修正 #290
- **【🔨修正】** バックパックの装備状態で「不明」を「未装備」と誤判定し、古いセーブデータのフィルター結果が誤る問題を修正
- **【🔨修正】** Yae のデータパケット処理が返却済みのプールされたバッファを参照して例外が発生する問題を修正
- **【🔨修正】** 予備ドメインの切り替えとリクエスト再試行を修正：URL のクエリパラメータを誤って書き換えず、非冪等リクエストを自動再試行しないように
- **【🔨修正】** アプリ終了時に処理がブロックされることがある問題を修正
- **【🔨修正】** 多言語リソースの HTML エスケープを修正し、ヒントテキストの太字表示を復元
