# 插件中心

插件中心是 Snap Hutao 提供的可擴展插件系統，允許用戶安裝和管理第三方插件，從而靈活擴展胡桃工具箱的功能。
所有已安裝的插件將在程序啟動時自動加載，用戶可在插件中心頁面統一管理。

## 安裝插件

![插件中心](/images/202608/plugin-center.webp)

::: tip 插件格式
胡桃工具箱的插件文件以 `.hutao` 為擴展名，實際為包含插件清單、程序集和可選資源文件的 ZIP 壓縮包。
:::

1. 打開胡桃工具箱，進入左側導航欄的**插件中心**頁面
2. 點擊工具欄上的**安裝插件**按鈕
3. 在文件選擇器中選擇一個 `.hutao` 插件文件
4. 程序將自動解壓並驗證插件包中的 `manifest.json`，確認無誤後完成安裝
5. 安裝成功後，插件將出現在插件列表中

## 管理插件

插件中心頁面以卡片形式展示所有已安裝的插件，每張卡片包含以下信息：

- **插件圖標**：由插件包內的 `icon.png` 提供，若無圖標則顯示默認圖標
- **插件名稱與描述**：來自插件清單中的 `name` 和 `description` 字段
- **版本號**：展示插件的當前版本
- **作者信息**：顯示插件的作者列表
- **狀態標識**：以彩色標籤展示插件當前處於**已啟用**或**已禁用**狀態

### 啟用與禁用插件

- 點擊插件卡片上的**啟用**按鈕可激活插件，程序將調用插件的 `OnEnable()` 生命週期方法
- 點擊**禁用**按鈕可停用插件，程序將調用插件的 `OnDisable()` 方法並釋放相關資源
- 啟用/禁用的狀態切換同時會重命名插件文件擴展名（`.hutao` ↔ `.hutaodisabled`）

### 卸載插件

1. 點擊插件卡片上的**卸載**按鈕
2. 在確認對話框中確認操作
3. 程序將先禁用插件，再刪除插件文件，完成卸載

### 其他操作

- **刷新**：點擊工具欄的刷新按鈕，重新掃描並加載插件目錄
- **打開插件目錄**：點擊工具欄的文件夾按鈕，在資源管理器中打開插件存放目錄

## 插件設置

如果插件提供了可配置的設置項，點擊插件卡片上的**設置**按鈕即可進入該插件的設置頁面。

設置頁面會根據設置項的值類型提供不同的輸入控件：

- **字符串類型**：使用文本輸入框（TextBox）
- **整數類型**：使用數字輸入框（NumberBox）
- **布爾類型**：使用開關控件（ToggleSwitch）

每個設置項均提供**保存**和**重置為默認值**按鈕，方便用戶調整和恢復設置。

## 遊戲內 DLL 注入

::: important 高級功能
DLL 注入為插件系統的高級功能，僅在通過胡桃工具箱啟動遊戲時生效。
:::

當用戶通過胡桃工具箱啟動遊戲時，程序會遍歷所有已啟用插件，檢查其插件包內是否包含 `inject/` 目錄。若存在該目錄，其中的所有 `.dll` 文件將被注入到遊戲進程中。

此功能允許插件在遊戲運行時與遊戲進行交互，實現更豐富的功能擴展。

## 插件開發

::: tip 開發者信息
如需開發自己的胡桃工具箱插件，請參考 `Snap.Hutao.Plugin.SDK` NuGet 包。該 SDK 提供了插件基類 `HutaoPlugin`、設置管理 `PluginSetting<T>`、自定義頁面 `PluginScopedPage` 等核心 API。
:::

插件開發的基本步驟：

1. 創建 .NET 類庫項目，安裝 `Snap.Hutao.Plugin.SDK` 包
2. 創建繼承 `HutaoPlugin` 的主類，並使用 `[PluginMain]` 特性標記
3. 實現 `OnInstall()`、`OnLoad()`、`OnEnable()`、`OnDisable()`、`OnUninstall()` 生命週期方法
4. 在 `manifest.json` 中填寫插件元數據（名稱、ID、版本、作者、描述）
5. 將編譯後的 DLL、`manifest.json` 和可選的 `icon.png` 打包為 `.hutao`（ZIP 格式）
