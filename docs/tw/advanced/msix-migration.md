# MSIX 升級與切換安裝方式

正式版 MSIX 2.0.1 和 2.0.2 的套件識別相同。直接安裝已簽署的 2.0.2 MSIX 即可沿用原有應用程式資料，無須手動移轉。

若要在 MSIX 與 Setup 之間切換，請先在設定中記下實際的資料目錄，完全結束胡桃（包括系統匣中的背景處理程序），再備份該目錄。安裝目標版本並確認它使用的資料目錄。如果目錄不同，請先結束胡桃並備份目標目錄的現有檔案，再複製所需的使用者資料，例如 `Userdata.db`。重新啟動後請核對帳號與祈願紀錄，確認成功前請保留備份及原安裝版本。部分設定可能需要重新設定。
