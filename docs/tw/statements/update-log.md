# 更新日誌
## 1.20.4 Release<Badge text="最新版" type="tip" />
- **【🎉新增】** 設置頁新增"控件材質"，可在原生 Fluent 與液態玻璃之間切換，並可預覽效果 #279

- **【🎉新增】** 添加 7.1 版本角色 ID 與新材料類型

- **【✨優化】** 重構插件系統：禁用插件時釋放程序集，插件設置的保存 / 重置會給出結果提示

- **【✨優化】** 背景圖片無法解碼時給出提示，不再靜默跳過
- **【✨優化】** 改進默認語言選擇和地區語言匹配：按系統 UI 語言匹配支持的語言，保留簡繁中文差異 #117
- **【✨優化】** 升級至 .NET 11 並更新依賴項

- **【🔨修復】** 修復開啟"自動以管理員模式重啟"後協議參數丟失，`hutao://launch/` 無法直接啟動遊戲 #305
