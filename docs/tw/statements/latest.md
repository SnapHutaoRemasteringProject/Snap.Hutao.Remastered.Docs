# 🎉 已成功更新至 1.20.4 版本

**簡體中文** | [English](/en/statements/latest.html)

- **【🎉新增】** 設置頁新增"控件材質"，可在原生 Fluent 與液態玻璃之間切換，並可預覽效果 #279
- **【🎉新增】** 液態玻璃支持按控件類型分別啟用，可調整模糊、折射、高光等光學參數並實時預覽 #279
- **【🎉新增】** 新增離線模式：無法連接服務器時改用本地倉庫列表，並提供重新連接入口
- **【🎉新增】**"我的角色"頁面支持按角色選擇聖遺物評分算法，可選米遊社推薦屬性、內置評分預設或自定義評分配置 #269
- **【🎉新增】** 揹包物品新增裝備狀態篩選（已裝備 / 未裝備）與裝備角色角標，詳情浮層展示裝備信息
- **【🎉新增】** 揹包聖遺物新增祝聖之霜標記與篩選，並可查看祝聖之霜定義的詞條
- **【🎉新增】** 聖遺物副詞條按有效 / 無效 / 雙爆 / 未激活著色，並展示未激活的第 4 條詞條
- **【🎉新增】** 主頁實時便箋卡片新增刷新按鈕 #281
- **【🎉新增】** 添加 7.1 版本角色 ID 與新材料類型

- **【✨優化】** 重構插件系統：禁用插件時釋放程序集，插件設置的保存 / 重置會給出結果提示
- **【✨優化】** Yae 升級至 5.5.0 協議，支持訂閱自定義數據包
- **【✨優化】** 優化揹包物品列表性能，減少切換與刷新時的卡頓
- **【✨優化】** 聖遺物評分配置對話框：取消不再落庫、刪除合併為單事務、切換預設不再被彈回、保存不再丟棄已有修改
- **【✨優化】** 優化背景視頻線程控制，降低後臺資源佔用
- **【✨優化】** 背景圖片無法解碼時給出提示，不再靜默跳過
- **【✨優化】** 改進默認語言選擇和地區語言匹配：按系統 UI 語言匹配支持的語言，保留簡繁中文差異 #117
- **【✨優化】** 升級至 .NET 11 並更新依賴項

- **【🔨修復】** 修復開啟"自動以管理員模式重啟"後協議參數丟失，`hutao://launch/` 無法直接啟動遊戲 #305
- **【🔨修復】** 修復養成計劃同步角色等級與天賦時未計入命座加成 #307
- **【🔨修復】** 修復養成計劃通過揹包存檔同步時部分區域特產數量無法同步 #280
- **【🔨修復】** 修復自動簽到只簽到當前賬號 #302
- **【🔨修復】** 修復背景視頻佔用系統 SMTC #290
- **【🔨修復】** 修復揹包裝備狀態將"未知"誤判為"未裝備"，導致舊存檔篩選結果錯誤
- **【🔨修復】** 修復 Yae 數據包處理時引用已歸還的池化緩衝區導致的異常
- **【🔨修復】** 修復備用域名切換與請求重試：不再錯誤改寫 URL 查詢參數，非冪等請求不再自動重試
- **【🔨修復】** 修復退出應用時可能阻塞的問題
- **【🔨修復】** 修復多語言資源中的 HTML 轉義，恢復提示文本的加粗顯示
