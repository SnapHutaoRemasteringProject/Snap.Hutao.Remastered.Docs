# 🎉 已成功更新至 2.0.1 版本

[简体中文](/zh/statements/latest.html) | **繁體中文** | [English](/en/statements/latest.html)

- **【🎉新增】** 新增「帳號歷史分析」獨立視窗，可從設定頁的網路設定區域，以及祈願紀錄、深境螺旋、幻想真境劇詩和幽境危戰頁面開啟 #335
- **【🎉新增】** 以本機儲存的紀錄繪製圖表：分別統計一般祈願與千星奇域祈願的每月抽數和卡池分布，以及深境螺旋星數、幻想真境劇詩獎章數和幽境危戰各難度的單人通關時間 #335
- **【🎉新增】** 帳號分析整合胡桃現有抽卡統計，使用五星角色與武器紀錄、平均出金抽數、目前墊抽、UP 和保底等資訊作為 AI 分析依據；不將缺漏的歷史紀錄當作零 #335
- **【🎉新增】** 帳號歷史分析新增選用 AI 助手，由使用者手動啟動分析，支援串流回答、Markdown 顯示與針對歷史資料的多輪追問 #335
- **【🎉新增】** AI 助手支援設定 OpenAI Chat Completions、OpenAI Responses 和 Anthropic 介面，並可自訂服務位址、API Key、模型和推理參數 #335
- **【🎉新增】** AI 助手支援儲存與管理對話、切換模型、重新產生回答、複製對話及檢視 Token 用量；工具呼叫需要授權時可核准或拒絕 #335
- **【🎉新增】** 液態玻璃 ToggleSwitch 新增整體縮放設定，預設為 0.7，僅調整開關圖形大小，不影響文字
- **【🎉新增】** 擴充液態玻璃光學參數及游標光照設定，並支援即時調整控制項效果
- **【🎉新增】** 自動更新新增「略過此版本」選項：自動檢查不再重複提醒，仍可在設定中手動檢查更新
- **【🎉新增】** Island 新增「凱瑟琳重新導向」，可將冒險之證的每日委託入口直接開啟委託獎勵確認視窗；需要相容的 Island 元件
- **【🎉新增】** 遊戲啟動頁新增手動重新整理安裝資訊，分別顯示 config.ini 與 ScriptVersion 的版本，並提示衝突、檔案遺失或讀取失敗
- **【🎉新增】** 可複製帳號歷史統計摘要以核對 AI 分析依據；已設定的模型 API Key 會儲存於 Windows 認證保管庫

- **【✨最佳化】** 預設啟用 ReadyToRun（R2R）預先編譯，減少執行時的 JIT 編譯開銷，有助於加快啟動與改善部分操作的回應速度，並完善 MSIX 和安裝程式的發佈流程 #334
- **【✨最佳化】** 改善 AI 模型自動取得、顯示名稱及下拉選取，提升 OpenAI 相容性；保留自訂名稱、參數和選取狀態，排除無效或重複的模型 ID
- **【✨最佳化】** AI 思考過程預設收合，可展開並捲動閱讀；改善模型設定面板、帳號分析視窗及危險操作按鈕的版面配置
- **【✨最佳化】** 改善液態玻璃參數的儲存與復原：被拒絕的設定可還原，避免覆蓋其他尚未儲存的變更
- **【✨最佳化】** 改善原生 Fluent 與液態玻璃的主題文字顏色、卡片圓角陰影、日曆素材圖示和簽到卡片遮罩 #325
- **【✨最佳化】** 改善 Flyout、ComboBox、NumberBox 等控制項的 Acrylic 材質和彈出層顯示
- **【✨最佳化】** 改善圖片快取非同步讀取、非同步鎖排程與頁面清理，減少介面執行緒阻塞及並行問題
- **【✨最佳化】** 改進成就匯入後的完成數量統計、引導頁導覽復原，並同步 Crowdin 多語言翻譯

- **【🔨修復】** 修復 config.ini 與 ScriptVersion 不一致時錯誤判斷遊戲版本的問題；版本不明時暫停依賴版本判斷的更新與預先下載，但仍可主動完整驗證及修復
- **【🔨修復】** 修復遊戲更新前後版本資訊可能不同步的問題：操作前重新檢查檔案，驗證資源成功後才更新版本資訊，保留渠道設定及備份，寫入失敗時還原
- **【🔨修復】** 修復 Island 啟用時未充分驗證已安裝遊戲版本與對應 DLL 相容性的問題；一般啟動不受影響
- **【🔨修復】** 修復非 MSIX 版開機啟動工作可能指向錯誤路徑，以及註冊失敗後設定開關狀態不同步的問題
- **【🔨修復】** 修復 AI 模型更新後名稱空白、選取項目遺失、新增模型時可能出現參數例外等問題，提升大量模型載入時的穩定性
- **【🔨修復】** 修復外部 AI 設定檔重新載入時，舊資料可能覆蓋較新的本機設定與 API 憑證修改
- **【🔨修復】** 修復 AI 對話工具呼叫核准／拒絕操作，以及部分工具名稱和參數顯示的資料繫結錯誤
- **【🔨修復】** 修復 MSIX 與安裝程式產物可能缺少原生執行階段程式庫及相依檔案，新增封裝前完整性檢查
- **【🔨修復】** 修復停用液態玻璃後部分控制項未恢復原生背景、樣板繫結錯誤及主題文字顏色異常 #317
- **【🔨修復】** 修復液態玻璃模式下部分下拉選單、彈出選單與控制項狀態未正確回饋 #308
- **【🔨修復】** 修復首頁即時便箋通知開關資料已變更，但介面未立即更新的問題
- **【🔨修復】** 修復角色選取、重複新增帳號及自動簽到讀取帳號清單時的跨執行緒存取問題 #318 #326
- **【🔨修復】** 修復快捷鍵啟用狀態在屬性變更通知重入時被舊值覆蓋 #327
- **【🔨修復】** 修復養成計畫刪除卡片後清單及共用彈出層未更新、已刪除項目仍被儲存，以及卡片操作被彈出層攔截 #329
- **【🔨修復】** 修復網路重試時無法正確重送請求內容，以及 Windows 工作階段鎖定和解除鎖定後背景影片播放狀態異常 #320 #323
- **【🔨修復】** 修復胡桃通行證重設密碼視窗可能出現參數例外，以及「移除對話跳過冷卻」確認倒數異常
- **【🔨修復】** 修復日曆素材切換材質時的繫結錯誤、部分至冬角色圖示與技能文字缺漏，以及祈願統計顯示切換操作 #313

> 提醒：AI 分析需自行設定模型服務並手動啟動。傳送給服務提供者的是歷史統計與抽卡摘要，不是完整帳號資料庫；即使移除 UID 等直接識別資訊，詳細歷史仍可能具有重新識別風險。使用前請確認第三方服務的隱私權政策。
