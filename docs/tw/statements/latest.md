# 🎉 已成功更新至 2.0.2 版本

**简体中文** [zh](/zh/statements/latest) · **繁體中文** [tw](/tw/statements/latest) · **English** [en](/en/statements/latest) · **日本語** [jp](/jp/statements/latest) · **Bahasa Indonesia** [id](/id/statements/latest) · **Русский** [ru](/ru/statements/latest)

本次更新新增 Windows 10 即時便箋動態磚，改善了**遊戲執行狀態偵測與處理程序管理**，向所有使用者開放 Island「凱瑟琳重新導向」，並修正部分使用者無法登入米遊社帳號的問題。

### 🎉 新增功能

- **【🎉新增】** 遊戲啟動頁可自動偵測從外部啟動的《原神》，顯示遊戲執行狀態，並提供結束遊戲處理程序的操作。
- **【🎉新增】** Island「凱瑟琳重新導向」設定現已向所有使用者開放。
- **【🎉新增】** Windows 10 的 MSIX 版新增即時便箋開始功能表動態磚，可顯示樹脂、每日委託等進度，並支援搜尋角色及選用角色名片作為背景。
- **【🎉新增】** Island 新增「舊版派蒙選單」選項，可恢復「千星商城」和「人氣奇域」在派蒙選單中的位置。
- **【🎉新增】** 安裝套件可附帶內建圖片。設定的快取資料夾區域新增「清理重複圖片快取」，僅移除與內建圖片內容相同的快取副本。

### ✨ 功能改善

- **【✨改善】** 減少不必要的處理程序掃描，並透過系統的處理程序結束通知即時更新遊戲執行狀態。
- **【✨改善】** 以一般權限執行時，也可嘗試結束以相同權限層級執行的遊戲處理程序。
- **【✨改善】** 改善結束遊戲處理程序後的狀態檢查，支援處理多個相符的程序，並在操作失敗時顯示更明確的錯誤訊息。
- **【✨改善】** MSIX 版和附帶圖片的 Setup 版在初次設定時跳過批次圖片下載，缺少的圖片會按需下載。一般 Setup 版仍可依類別預先下載。
- **【✨改善】** 為凱瑟琳重新導向加入附動畫的操作提示。
- **【✨改善】** 讓各視窗及對話框套用已儲存的佈景主題，並改善設定頁動畫與介面翻譯。
- **【✨改善】** 更新對《原神》7.1 新材料類別的支援。

### 🔨 問題修正

- **【🔨修正】** 修正部分使用者無法登入米遊社帳號的問題。
- **【🔨修正】** 修正從外部啟動或關閉遊戲後，遊戲執行狀態可能未即時更新的問題。
- **【🔨修正】** 修正遊戲處理程序結束後，Island 可能仍顯示為已連線的問題。
- **【🔨修正】** 修正部分唯讀屬性的變更通知未能觸發 `x:Bind` 介面重新整理的問題，改善遊戲啟動頁的狀態同步。
- **【🔨修正】** 修正結束遊戲時，因部分處理程序無法存取或同時存在多個相符的程序而導致的異常。
- **【🔨修正】** 修正遠端功能設定擷取失敗後，失敗結果快取過久而無法及時重試的問題。
- **【🔨修正】** 修正祈願紀錄擷取頁面的清單無法捲動的問題。
- **【🔨修正】** 修正即時便箋卡片的重新整理時間與 UID 重疊的問題。
- **【🔨修正】** 修正 Island 帳號驗證遇到網路錯誤或逾時時可能關閉遊戲的問題，現在會顯示提示並讓遊戲繼續執行。
- **【🔨修正】** 修正 `config.ini` 有重複 `game_version` 時的版本識別及修復問題，並改善 INI 註解及區段標題的處理方式。
- **【🔨修正】** 分開查詢一般祈願與千星奇域祈願，改善手動輸入及網頁快取祈願連結的驗證，並補上祈願中繼資料缺失時的在地化提示。
- **【🔨修正】** 修正同步背包物品失敗時可能清除既有資料的問題。
- **【🔨修正】** 修正初次設定期間卡住的圖片下載可能無法及時結束的問題。
- **【🔨修正】** 修正清除外掛程式設定後仍套用舊值的問題，以及部分下拉式選項內容空白的問題。
- **【🔨修正】** 修正關閉視窗後的結束等待流程與部分帳號初始化時的錯誤。
- **【🔨修正】** 恢復挪德卡萊和至冬的角色歸屬圖示。

### 使用提示

如果遊戲以較高權限執行，可能仍需以系統管理員身分啟動胡桃才能結束遊戲處理程序。
