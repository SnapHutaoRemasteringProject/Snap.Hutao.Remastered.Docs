# 更新日志
## 2.0.1 Release<Badge text="最新版" type="tip" />
- **【🎉新增】** 新增「账号历史分析」独立窗口，可从设置页的网络设置区域，以及祈愿记录、深境螺旋、幻想真境剧诗、幽境危战页面打开 #335
- **【🎉新增】** 基于本地保存的历史记录绘制图表：分别统计普通祈愿和千星奇域颂愿的月度抽数、卡池分布，以及深境螺旋星数、幻想真境剧诗奖章数和幽境危战各难度单人通关耗时 #335
- **【🎉新增】** 账号分析结合胡桃现有抽卡统计，提供五星角色与武器记录、平均出金抽数、当前垫抽、UP 与保底等数据作为 AI 分析依据；历史不完整时不会将缺失记录当作零 #335
- **【🎉新增】** 账号历史分析内新增可选的 AI 助手：由用户主动发起分析，支持流式回复、Markdown 显示及针对历史数据的多轮追问 #335
- **【🎉新增】** AI 助手支持配置 OpenAI Chat Completions、OpenAI Responses 和 Anthropic 接口，允许自定义服务地址、API Key、模型和推理参数 #335
- **【🎉新增】** AI 助手支持保存及管理历史会话、切换模型、重新生成回答、复制对话和查看 Token 用量；需要工具授权时提供批准或拒绝操作 #335
- **【🎉新增】** 液态玻璃 ToggleSwitch 新增整体缩放比例设置，默认 0.7，仅缩放开关图形，不改变文字大小
- **【🎉新增】** 扩展液态玻璃光学参数及指针光照设置，并支持实时调整控件效果
- **【🎉新增】** 自动更新提示新增「跳过此版本」：自动检查将不再重复提示该版本，仍可在设置页手动检查更新
- **【🎉新增】** Island 新增「凯瑟琳重定向」选项，可将冒险之证中的每日委托入口改为直接打开凯瑟琳的委托奖励确认弹窗；需要兼容的 Island 组件
- **【🎉新增】** 游戏启动页新增安装信息手动刷新，分别显示 config.ini 与 ScriptVersion 中的版本信息，并提示版本冲突、文件缺失或读取失败
- **【🎉新增】** 可复制账号历史统计摘要以核对 AI 分析依据；已配置的模型 API Key 使用 Windows 凭据保管库保存

- **【✨优化】** 默认启用 ReadyToRun（R2R）预编译，减少运行时即时编译开销，有助于加快应用启动和改善部分场景的响应速度，并完善 MSIX 与安装程序的发布流程 #334
- **【✨优化】** 优化 AI 模型自动获取、模型名称与下拉选择：兼容更多 OpenAI 风格接口，保留自定义名称、参数和选中项，并过滤无效或重复的模型 ID
- **【✨优化】** 优化 AI 思考过程展示，默认折叠并支持展开滚动查看；改进模型设置面板、账号分析窗口与危险操作按钮的布局
- **【✨优化】** 增强液态玻璃参数的保存与恢复：应用不接受的配置会回退，不会轻易覆盖其他尚未保存的调整
- **【✨优化】** 优化原生 Fluent 与液态玻璃的主题颜色、卡片圆角和阴影，以及日历素材图标、签到卡片遮罩 #325
- **【✨优化】** 改进 Flyout、ComboBox、NumberBox 等控件的 Acrylic 材质适配和弹出层表现
- **【✨优化】** 优化图片缓存的异步读取、异步锁调度与页面清理，减少界面线程阻塞及部分并发问题
- **【✨优化】** 改进成就导入后的已完成数量统计、引导页导航恢复，并同步 Crowdin 多语言翻译

- **【🔨修复】** 修复 config.ini 与 ScriptVersion 内容冲突时错误判断游戏安装版本的问题；版本无法确定时暂停依赖版本判断的更新与预下载，仍可主动执行完整校验和修复
- **【🔨修复】** 修复游戏更新前后版本信息可能不同步的问题：准备操作时重新核对文件，资源验证成功后才更新版本记录，并保留渠道配置及备份、在写入失败时回滚
- **【🔨修复】** 修复启用 Island 时未充分检查已安装游戏版本与对应 DLL 兼容性的问题；不影响不使用 Island 的正常启动
- **【🔨修复】** 修复非 MSIX 安装版的开机自启动任务可能指向错误路径，以及注册失败后设置开关状态不一致的问题
- **【🔨修复】** 修复 AI 模型列表刷新后名称空白、已选模型丢失、添加模型可能抛出参数异常等问题，并改善大量模型加载的稳定性
- **【🔨修复】** 修复外部 AI 设置文件刷新时，旧快照可能覆盖较新的本地配置和 API 凭据修改的问题
- **【🔨修复】** 修复 AI 对话中工具调用的批准／拒绝操作以及部分工具名称、参数展示的绑定错误
- **【🔨修复】** 修复 MSIX 和安装程序的发布产物可能遗漏原生运行库及依赖文件的问题，增加打包前完整性检查
- **【🔨修复】** 修复关闭液态玻璃后部分控件仍保留玻璃背景、模板绑定异常和主题文字颜色不正确的问题 #317
- **【🔨修复】** 修复液态玻璃模式下部分下拉框、弹出菜单及控件状态变化没有正确反馈的问题 #308
- **【🔨修复】** 修复主页实时便笺通知开关数据已变化但界面未立即更新的问题
- **【🔨修复】** 修复账号角色选择、重新添加已有账号及自动签到读取账号列表时可能发生的跨线程访问问题 #318 #326
- **【🔨修复】** 修复热键启用状态在属性变更通知重入时可能被旧值覆盖的问题 #327
- **【🔨修复】** 修复养成计划删除卡片后列表和共用弹层未更新、已删除项仍可能被保存，以及卡片操作被弹层抢占的问题 #329
- **【🔨修复】** 修复网络重试请求无法正确重放消息内容，以及 Windows 会话锁定、解锁后背景视频的播放状态异常 #320 #323
- **【🔨修复】** 修复胡桃通行证重置密码弹窗可能出现参数异常，以及「移除对话跳过冷却」二次确认倒计时异常
- **【🔨修复】** 修复日历材料切换材质时的绑定问题、部分至冬角色图标和技能说明缺字问题，并修正祈愿统计切换显示的交互 #313
