# 🎉 已成功更新至 2.0.2 版本

**简体中文** [zh](/zh/statements/latest) · **繁體中文** [tw](/tw/statements/latest) · **English** [en](/en/statements/latest) · **日本語** [jp](/jp/statements/latest) · **Bahasa Indonesia** [id](/id/statements/latest) · **Русский** [ru](/ru/statements/latest)

本次更新新增 Windows 10 实时便笺磁贴，改进了**游戏运行状态检测与进程管理**，向所有用户开放 Island「凯瑟琳重定向」，并修复了部分用户无法登录米游社账户的问题。

### 🎉 新增功能

- **【🎉新增】** 游戏启动页可自动检测从外部启动的《原神》，显示游戏运行状态，并提供结束游戏进程的操作。
- **【🎉新增】** Island「凯瑟琳重定向」设置现已向所有用户开放。
- **【🎉新增】** Windows 10 的 MSIX 版新增实时便笺开始菜单磁贴，可显示树脂、每日委托等进度，并支持搜索角色、选用角色名片作为背景。
- **【🎉新增】** Island 新增「旧版派蒙菜单」选项，可恢复「千星商城」和「人气奇域」在派蒙菜单中的位置。
- **【🎉新增】** 安装包可附带内置图片。设置的缓存文件夹区域新增「清理重复图片缓存」，仅移除与内置图片内容相同的缓存副本。

### ✨ 功能优化

- **【✨优化】** 减少不必要的进程扫描，并通过系统的进程退出通知及时更新游戏运行状态。
- **【✨优化】** 普通权限下也可尝试结束以相同权限级别运行的游戏进程。
- **【✨优化】** 改进结束游戏进程后的状态检查，支持处理多个匹配的进程，并在操作失败时提供更明确的错误提示。
- **【✨优化】** MSIX 版和附带图片的 Setup 版在初次设置时跳过批量图片下载，缺少的图片按需获取。普通 Setup 版仍可按类别预下载。
- **【✨优化】** 为凯瑟琳重定向加入带动图的操作提示。
- **【✨优化】** 让各窗口和对话框应用已保存的主题，并改进设置页动画及界面翻译。
- **【✨优化】** 更新对《原神》7.1 新材料类别的支持。

### 🔨 问题修复

- **【🔨修复】** 修复部分用户无法登录米游社账户的问题。
- **【🔨修复】** 修复从外部启动或关闭游戏后，游戏运行状态可能未及时更新的问题。
- **【🔨修复】** 修复游戏进程退出后，Island 可能仍显示为已连接的问题。
- **【🔨修复】** 修复部分只读属性的变更通知未能触发 `x:Bind` 界面刷新的问题，改善游戏启动页的状态同步。
- **【🔨修复】** 修复结束游戏时，因部分进程无法访问或同时存在多个匹配进程而导致的异常。
- **【🔨修复】** 修复远程功能配置获取失败后，失败结果缓存过久、无法及时重试的问题。
- **【🔨修复】** 修复祈愿记录获取页面的列表无法滚动的问题。
- **【🔨修复】** 修复实时便笺卡片的刷新时间与 UID 重叠的问题。
- **【🔨修复】** 修复 Island 账号校验遇到网络异常或超时时可能退出游戏的问题，现会显示提示并让游戏继续运行。
- **【🔨修复】** 修复 `config.ini` 存在重复 `game_version` 键时的版本识别和修复问题，并改进对 INI 注释与节标题的处理。
- **【🔨修复】** 分开查询普通祈愿与千星奇域祈愿，改进手动输入及网页缓存祈愿链接的校验，并补充祈愿元数据缺失时的本地化提示。
- **【🔨修复】** 修复背包物品同步失败时可能清空已有数据的问题。
- **【🔨修复】** 修复首次设置下载图片资源时，卡住的下载可能无法及时结束的问题。
- **【🔨修复】** 修复清除插件设置后仍沿用旧值的问题，也修复了部分下拉选项内容为空的问题。
- **【🔨修复】** 修复关闭窗口后的退出等待逻辑，以及部分账号初始化时的异常。
- **【🔨修复】** 恢复挪德卡莱和至冬的角色归属图标。

### 使用提示

如果游戏以更高权限运行，可能仍需以管理员身份启动胡桃才能结束游戏进程。
