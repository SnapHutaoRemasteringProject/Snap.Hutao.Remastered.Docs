# 🎉 已成功更新至 1.20.4 版本

**简体中文** | [English](/en/statements/latest.html)

- **【🎉新增】** 设置页新增"控件材质"，可在原生 Fluent 与液态玻璃之间切换，并可预览效果 #279
- **【🎉新增】** 液态玻璃支持按控件类型分别启用，可调整模糊、折射、高光等光学参数并实时预览 #279
- **【🎉新增】** 新增离线模式：无法连接服务器时改用本地仓库列表，并提供重新连接入口
- **【🎉新增】**"我的角色"页面支持按角色选择圣遗物评分算法，可选米游社推荐属性、内置评分预设或自定义评分配置 #269
- **【🎉新增】** 背包物品新增装备状态筛选（已装备 / 未装备）与装备角色角标，详情浮层展示装备信息
- **【🎉新增】** 背包圣遗物新增祝圣之霜标记与筛选，并可查看祝圣之霜定义的词条
- **【🎉新增】** 圣遗物副词条按有效 / 无效 / 双爆 / 未激活着色，并展示未激活的第 4 条词条
- **【🎉新增】** 主页实时便笺卡片新增刷新按钮 #281
- **【🎉新增】** 添加 7.1 版本角色 ID 与新材料类型

- **【✨优化】** 重构插件系统：禁用插件时释放程序集，插件设置的保存 / 重置会给出结果提示
- **【✨优化】** Yae 升级至 5.5.0 协议，支持订阅自定义数据包
- **【✨优化】** 优化背包物品列表性能，减少切换与刷新时的卡顿
- **【✨优化】** 圣遗物评分配置对话框：取消不再落库、删除合并为单事务、切换预设不再被弹回、保存不再丢弃已有修改
- **【✨优化】** 优化背景视频线程控制，降低后台资源占用
- **【✨优化】** 背景图片无法解码时给出提示，不再静默跳过
- **【✨优化】** 改进默认语言选择和地区语言匹配：按系统 UI 语言匹配支持的语言，保留简繁中文差异 #117
- **【✨优化】** 升级至 .NET 11 并更新依赖项

- **【🔨修复】** 修复开启"自动以管理员模式重启"后协议参数丢失，`hutao://launch/` 无法直接启动游戏 #305
- **【🔨修复】** 修复养成计划同步角色等级与天赋时未计入命座加成 #307
- **【🔨修复】** 修复养成计划通过背包存档同步时部分区域特产数量无法同步 #280
- **【🔨修复】** 修复自动签到只签到当前账号 #302
- **【🔨修复】** 修复背景视频占用系统 SMTC #290
- **【🔨修复】** 修复背包装备状态将"未知"误判为"未装备"，导致旧存档筛选结果错误
- **【🔨修复】** 修复 Yae 数据包处理时引用已归还的池化缓冲区导致的异常
- **【🔨修复】** 修复备用域名切换与请求重试：不再错误改写 URL 查询参数，非幂等请求不再自动重试
- **【🔨修复】** 修复退出应用时可能阻塞的问题
- **【🔨修复】** 修复多语言资源中的 HTML 转义，恢复提示文本的加粗显示
