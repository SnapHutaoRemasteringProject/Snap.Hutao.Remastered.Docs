# MSIX 升级与安装方式切换

正式版 MSIX 2.0.1 和 2.0.2 的包标识相同。直接安装已签名的 2.0.2 MSIX 即可沿用原有应用数据，无需手动迁移。

如果要在 MSIX 和 Setup 之间切换，请先在设置中记录实际数据目录，完全退出胡桃（包括托盘中的后台进程），然后备份该目录。安装目标版本并确认其实际数据目录。如果两个目录不同，请退出胡桃，备份目标目录中的现有文件，再将需要的用户数据（例如 `Userdata.db`）复制到目标目录。重新启动后核对账号和祈愿记录，确认成功前请保留备份和原安装。部分设置可能需要重新配置。
