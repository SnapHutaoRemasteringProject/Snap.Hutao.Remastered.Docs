# Memperbarui MSIX atau mengganti jenis instalasi

Paket MSIX resmi 2.0.1 dan 2.0.2 memakai identitas paket yang sama. Instal MSIX 2.0.2 bertanda tangan di atas versi 2.0.1 untuk tetap menggunakan data aplikasi yang ada.

Untuk beralih antara MSIX dan Setup, periksa direktori data di Pengaturan, tutup Snap Hutao sepenuhnya termasuk dari baki sistem, lalu cadangkan direktori tersebut. Instal edisi tujuan dan periksa direktori data yang digunakannya. Jika berbeda, tutup Snap Hutao, cadangkan berkas yang sudah ada di direktori tujuan, lalu salin data yang diperlukan, seperti `Userdata.db`. Buka kembali aplikasi dan periksa akun serta riwayat Wish. Simpan cadangan dan instalasi lama sampai pemindahan berhasil diverifikasi. Beberapa pengaturan mungkin perlu diatur kembali.
