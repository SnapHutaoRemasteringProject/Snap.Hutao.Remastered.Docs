# 🎉 Berhasil Memperbarui ke Versi 2.0.2

**简体中文** [zh](/zh/statements/latest) · **繁體中文** [tw](/tw/statements/latest) · **English** [en](/en/statements/latest) · **日本語** [jp](/jp/statements/latest) · **Bahasa Indonesia** [id](/id/statements/latest) · **Русский** [ru](/ru/statements/latest)

Versi ini meningkatkan deteksi dan penghentian proses game, membuka pengaturan Catherine Redirect untuk semua pengguna, serta memperbarui identitas MSIX untuk Microsoft Store. **Mulai 2.0.2, MSIX hanya tersedia di Store; data MSIX lama perlu dimigrasikan manual.**

### 🎉 Fitur Baru
- **【🎉】** Mendeteksi Genshin Impact yang dibuka di luar Snap Hutao dan menyediakan status serta fungsi penghentian game.
- **【🎉】** Pengaturan Island Catherine Redirect tersedia untuk semua pengguna.

### ✨ Peningkatan
- **【✨】** Mengurangi pemindaian proses dengan memakai pemberitahuan keluar dari OS selama game berjalan.
- **【✨】** Mengizinkan penghentian game dengan hak setara tanpa administrator, serta memperbaiki penanganan banyak proses dan pesan akses ditolak.
- **【✨】** Menghubungkan MSIX rilis dengan identitas Microsoft Store. GitHub tetap menyediakan Setup; pembaruan MSIX kini melalui Store.

### 🔨 Perbaikan Masalah
- **【🔨】** Memperbaiki status game yang tidak diperbarui setelah peluncuran atau penutupan eksternal.
- **【🔨】** Memperbaiki status Island yang tertinggal setelah game berhenti dan sebagian notifikasi x:Bind read-only yang tidak memperbarui UI.
- **【🔨】** Memperbaiki hasil konfigurasi fitur jarak jauh yang gagal tetapi tetap disimpan lama sehingga tidak bisa dicoba lagi.
- **【🔨】** Memperbaiki daftar di halaman pengambilan riwayat Wish yang tidak dapat digulir.
