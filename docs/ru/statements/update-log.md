# Журнал обновлений
## 1.19.5 Release<Badge text="Последняя версия" type="tip" />
- **【🎉Новое】** Поддержка Unpackaged режима — запуск напрямую через .exe без упаковки MSIX
- **【🎉Новое】** Автообновление для не-MSIX установок (установщик Inno Setup)
- **【🎉Новое】** Улучшения облачной синхронизации Beyond Gacha Log (Thousand-Star Realm)
- **【🎉Новое】** Переключение отображения календаря событий при смене аккаунта #107
- **【🎉Новое】** Полная совместимость со всеми версиями UIGF для импорта/экспорта

- **【✨Оптимизация】** Оптимизация скорости запуска — пропуск предсборочной валидации в Release, поэтапная инициализация
- **【✨Оптимизация】** Рефакторинг сборочной системы Cake — единая сборка MSIX + Installer, автоудаление onnxruntime.dll
- **【✨Оптимизация】** Удаление code-behind со страницы молитв
- **【✨Оптимизация】** Обновление значка при отсутствии загруженных плагинов
- **【✨Оптимизация】** Удаление неиспользуемых статических ресурсов (LoadingPic и др.)

- **【🔨Исправление】** Ошибка реализации разблокировки Loopback
- **【🔨Исправление】** Аномалия отображения общего количества круток после смены аккаунта #150
- **【🔨Исправление】** Невозможность перезапуска от имени администратора в режиме Unpackaged
- **【🔨Исправление】** Второй экземпляр не завершается корректно в некоторых случаях
- **【🔨Исправление】** Токен Hutao Passport не обновляется повторно
- **【🔨Исправление】** Отображение сообщения об ошибке при сбое запуска
- **【🔨Исправление】** Неправильные имена полей локализации

## 1.19.2 Release

- **【🎉Новое】** На главной странице отображается календарь игровых событий текущей версии
- **【🎉Новое】** В настройках отображается календарь игровых событий текущей версии, которые еще не начались

- **【✨Оптимизация】** Оптимизирована скорость загрузки главной страницы
- **【✨Оптимизация】** Оптимизирована логика обновления автозапуска приложения без прав администратора

- **【🔨Исправление】** Исправлена проблема отображения диалога аккаунта пропуска

## 1.19.1 Release

- **【🎉Новое】** Страница "Мои персонажи" поддерживает пакетный экспорт статуса развития персонажей в виде текстовых документов [#82]
- **【🎉Новое】** Главный интерфейс отображает обратный отсчет оставшегося времени события [#76]
- **【🎉Новое】** Отображение статуса фоновых задач, чтобы избежать ошибочной оценки как неотзывчивых
- **【🎉Новое】** Функция автоматического запуска программы (полная поддержка Win11, ограниченная поддержка Win10)
- **【🎉Новое】** Новый интерфейс отображения прогресса загрузки обновлений (не окончательный вариант, все еще оптимизируется)
- **【🎉Новое】** Поддержка приостановки и возобновления во время процессов обновления/восстановления игры
- **【🎉Новое】** Пользовательский запуск: позволяет запускать больше приложений одним щелчком при запуске игры

- **【✨Оптимизация】** Адаптация внутреннего обновления программы [#96]
- **【✨Оптимизация】** Добавлено напоминание сопровождающего на этапе OOBE: Snap Hutao Remastered не поддерживается оригинальным автором [#90]
- **【✨Оптимизация】** Функции автоматически восстанавливаются после восстановления сетевой среды при запуске
- **【✨Оптимизация】** Оптимизирован механизм проверки сбоя входа в учетную запись Hutao

- **【🔨Исправление】** Исправлена проблема, когда процесс не завершается после закрытия игры [#98]
- **【🔨Исправление】** Исправлено аномальное завершение игрового процесса [#92]
- **【🔨Исправление】** Исправлено исключение при обновлении записей о желаниях [#78]
- **【🔨Исправление】** Исправлена ошибка при добавлении развития персонажа [#87]
- **【🔨Исправление】** Обработана проблема, когда Deployment.exe ложно определяется некоторым антивирусным ПО как Malgent!MSR [#91]
- **【🔨Исправление】** Исправлена проблема, когда окно может не закрываться при отмене загрузки обновления игры
- **【🔨Исправление】** Исправлено наложение текста на кнопке паузы

## 1.19.0 Release

- **【✨Оптимизация】** Удален процесс настройки времени (#66)  

- **【🔨Исправление】** Исправлена проблема, при которой обновление stoken вызывает дублирование импорта всех записей о желаниях (#74)  
- **【🔨Исправление】** Исправлена аномальная дрожь полосы прогресса при двойном нажатии кнопки "Проверить обновления" во время обновления версии (#67)  
- **【🔨Исправление】** Исправлена проблема "Нет реакции на обновление" (#64)
