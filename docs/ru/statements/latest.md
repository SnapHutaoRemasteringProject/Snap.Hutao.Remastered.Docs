# 🎉 Успешное обновление до версии 2.0.2

**简体中文** [zh](/zh/statements/latest) · **繁體中文** [tw](/tw/statements/latest) · **English** [en](/en/statements/latest) · **日本語** [jp](/jp/statements/latest) · **Bahasa Indonesia** [id](/id/statements/latest) · **Русский** [ru](/ru/statements/latest)

Улучшены обнаружение и завершение игровых процессов, синхронизация Island и доступность функции Catherine Redirect. **Начиная с 2.0.2, MSIX доступен только через Microsoft Store; данные старого пакета переносятся вручную.**

### 🎉 Новые функции
- **【🎉】** Определение Genshin Impact, запущенного вне Snap Hutao, с отображением статуса и возможностью завершения.
- **【🎉】** Настройка Island Catherine Redirect доступна всем пользователям.

### ✨ Улучшения
- **【✨】** Сокращено сканирование процессов: при запущенной игре используются уведомления ОС о завершении.
- **【✨】** Завершение процессов с теми же правами возможно без запуска Snap Hutao от администратора; улучшены обработка нескольких процессов и ошибок доступа.
- **【✨】** MSIX связан с идентификатором Microsoft Store. GitHub продолжит выпуск Setup, а обновления MSIX будут поставляться через Store.

### 🔨 Исправления
- **【🔨】** Исправлено несвоевременное обновление состояния игры при запуске и выходе вне Snap Hutao.
- **【🔨】** Исправлены устаревшее подключение Island после выхода и отсутствие обновлений некоторых привязок x:Bind для свойств только для чтения.
- **【🔨】** Исправлено долгое кэширование ошибок загрузки удалённой конфигурации, мешавшее повторной попытке.
- **【🔨】** Исправлена прокрутка списка на странице получения истории молитв.
