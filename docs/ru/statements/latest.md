# 🎉 Успешно обновлено до версии 1.20.4

**简体中文** | [English](/en/statements/latest.html)

- **【🎉Новое】** В настройки добавлен пункт «Материал элементов управления» с переключением между нативным Fluent и жидким стеклом и предпросмотром #279
- **【🎉Новое】** Жидкое стекло можно включать отдельно для каждого типа элементов управления, настраивая размытие, преломление, блики и другие оптические параметры с предпросмотром в реальном времени #279
- **【🎉Новое】** Добавлен автономный режим: при недоступности сервера используется локальный список репозиториев, предусмотрено повторное подключение
- **【🎉Новое】** На странице «Мои персонажи» теперь можно выбрать алгоритм оценки артефактов для каждого персонажа: рекомендуемые характеристики HoYoLAB, встроенные предустановки оценки или пользовательские конфигурации оценки #269
- **【🎉Новое】** В рюкзаке добавлены фильтры состояния экипировки (экипировано / не экипировано) и значок персонажа-владельца, а во всплывающей панели отображается информация об экипировке
- **【🎉Новое】** Артефакты в рюкзаке теперь имеют отметку освящающего эликсира и фильтр по ней; можно просмотреть субхарактеристики, заданные освящающим эликсиром
- **【🎉Новое】** Субхарактеристики артефактов окрашиваются как действительные / недействительные / двойной крит / неактивные, а неактивная четвёртая субхарактеристика отображается
- **【🎉Новое】** На карточку «Заметки в реальном времени» на главной странице добавлена кнопка обновления #281
- **【🎉Новое】** Добавлены ID персонажей версии 7.1 и новые типы материалов

- **【✨Оптимизация】** Система плагинов переработана: при отключении плагина его сборки освобождаются, а сохранение / сброс настроек плагина сопровождается уведомлением
- **【✨Оптимизация】** Yae обновлён до протокола 5.5.0 с поддержкой подписки на пользовательские пакеты
- **【✨Оптимизация】** Повышена производительность списка предметов рюкзака, меньше подтормаживаний при переключении и обновлении
- **【✨Оптимизация】** Диалог настройки оценки артефактов: отмена больше не сохраняет, удаление выполняется в одной транзакции, переключение предустановок не откатывается, сохранение не теряет уже внесённые изменения
- **【✨Оптимизация】** Улучшено управление потоками фонового видео, снижено потребление ресурсов в фоне
- **【✨Оптимизация】** При невозможности декодировать фоновое изображение теперь показывается подсказка вместо тихого пропуска
- **【✨Оптимизация】** Улучшены выбор языка по умолчанию и сопоставление региональных языков: поддерживаемые языки подбираются по языку интерфейса системы, различие упрощённого и традиционного китайского сохраняется #117
- **【✨Оптимизация】** Обновление до .NET 11 и зависимостей

- **【🔨Исправление】** Исправлена потеря аргументов протокола при включённом «Автоматическом перезапуске от имени администратора», из-за чего `hutao://launch/` не запускал игру напрямую #305
- **【🔨Исправление】** Исправлено, что синхронизированные в плане развития уровни и таланты персонажей не учитывали бонусы созвездий #307
- **【🔨Исправление】** Исправлено, что часть местных диковинок не синхронизировалась при синхронизации плана развития через сохранение рюкзака #280
- **【🔨Исправление】** Исправлено, что автоматическая отметка выполнялась только для текущего аккаунта #302
- **【🔨Исправление】** Исправлено, что фоновое видео занимало системный SMTC #290
- **【🔨Исправление】** Исправлено, что состояние экипировки в рюкзаке принимало «неизвестно» за «не экипировано», из-за чего фильтры старых сохранений работали неверно
- **【🔨Исправление】** Исправлено исключение при обработке пакетов Yae из-за обращения к уже возвращённому буферу из пула
- **【🔨Исправление】** Исправлены переключение резервного домена и повтор запросов: параметры запроса в URL больше не искажаются, а неидемпотентные запросы не повторяются автоматически
- **【🔨Исправление】** Исправлено возможное зависание при выходе из приложения
- **【🔨Исправление】** Исправлено экранирование HTML в ресурсах локализации, восстановлено жирное начертание подсказок
