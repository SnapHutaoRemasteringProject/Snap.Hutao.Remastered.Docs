# Перенос данных со старого MSIX в Microsoft Store

Начиная с 2.0.2, идентификатор пакета MSIX изменён. Windows создаёт отдельное хранилище для версии Store, поэтому данные и настройки старой версии не переносятся автоматически.

::: warning
Не заменяйте файлом старой версии `settings.dat` новые настройки, которые могут содержать специфичные для пакета значения или старые пути.
:::

1. Проверьте **фактическую папку данных** в старой версии, в том числе пользовательский путь. Сделайте полную резервную копию и закройте обе версии, включая процессы в области уведомлений.

2. Откройте в Проводнике `%LOCALAPPDATA%\Packages` и найдите папку старого пакета с началом `E8B6E2B3-D2A0-4435-A81D-2A16AAF405C8_`. Стандартные данные обычно находятся в `LocalState\Hutao`; при изменённом пути используйте его.

3. Установите версию Microsoft Store, запустите один раз и полностью закройте. Новая папка пакета начинается с `SnapHutaoRemasteringProje.SnapHutaoRemastered_`, стандартные данные расположены в `LocalState\Hutao`.

4. Сначала сохраните копию целевых файлов, затем перенесите нужные данные, например `Userdata.db` и каталоги ресурсов, в **фактическую папку данных нового приложения**. Не перезаписывайте целиком `Packages` или `LocalState`.

5. Откройте Store-версию и проверьте аккаунты, молитвы и историю. `LocalSettings` относятся к конкретному пакету, поэтому настройки, учётные данные и вход может потребоваться восстановить вручную. Сохраните старую версию и резервную копию до проверки.
