# Устаревшая установка MSIX вручную (архив)

::: warning
Этот раздел относится только к старым MSIX-пакетам (2.0.1 и ранее). С версии 2.0.2 Snap Hutao Remastered MSIX распространяется только через Microsoft Store; новые MSIX-файлы больше не публикуются на GitHub.
:::

Для установки и обновления последней версии см. [Краткое руководство](/ru/quick-start).

Перед переходом со старого MSIX сохраните резервную копию и прочитайте [руководство по переносу данных](/ru/advanced/msix-migration). Разные идентификаторы пакетов не позволяют автоматически перенести старые данные.

Установщик Setup.exe по-прежнему доступен в [GitHub Releases](https://github.com/SnapHutaoRemasteringProject/Snap.Hutao.Remastered/releases/latest).
